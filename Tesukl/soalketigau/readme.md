Soal sulit pertama latihan ukl

Program bekerja dengan menghitung inputan data pengguna menjumlahkannya lalu memberikan rata ratanya

Soal sulit kedua latihan ukl

Program menanyakan kepada pengguna untuk menginputkan data matriks pertama dan data matriks kedua, jika jumlah kolom dan baris matriks tersebut sama maka program akan menjumlahkan kedua matriks dan mengoutputkan hasil penjumlahan tersebut ke pengguna
